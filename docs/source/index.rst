MASAFI Sim Petri documentation
==============================

Petri nets for discrete event simulation.

This library models and simulates Petri nets. It is a library only: the
graphical editor that builds the nets is a separate application that imports
this package.

Installation
------------

.. code-block:: bash

   pip install -e ".[dev,docs]"
